# 桌面宠物 DesktopPet

一个用 Python + tkinter 实现的常驻桌面小宠物。

## 功能
- 常驻桌面，无边界框
- 鼠标拖拽移动手

## 环境要求
- Python 3.10 及以上
- tkinter（一般随 Python 自带；若缺失运行 `pip install tk`）

## 运行方法
1. 确认已安装 Python 3.10 及以上（可在终端输入 `python --version` 查看）。
2. 在本项目文件夹中打开终端（PowerShell 或 Git Bash 均可）。
3. 运行：
      python naishupet.py

## 更新版本
